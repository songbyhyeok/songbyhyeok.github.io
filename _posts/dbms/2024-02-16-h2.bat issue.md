# 시도
1. 폴더로 물리적 접근을 통해 직접 실행
2. cmd 프롬프트를 통해 경로 접근하여 h2.bat 실행
3. cmd 프롬프트를 통해 경로 접근하여 "h2.bat" 실행 (따옴표를 붙여 실행)
4. JDK 설치 확인 및 JAVA_HOME 변수 값에 JDK 설치 경로가 제대로 설정이 되어있는지 확인

# 해결
1 ~ 4 모두 시도해 보았고, 4번이 문제였단 것을 알게 되었다.  
최근 프로그램 정리를 했었던 적이 있었고, 프로그램 설치 경로들이 변경되면서 JAVA_HOME에 JDK 위치 설정이 제대로 안 잡혀있었고 JDK를 17버전으로 업그레이드 후 다시 위치 재설정을 해 주고 h2.bat를 실행했더니 정상 작동이 되었다.  
이를 통해 Java JVM 시스템 위에서 H2 DBMS Engine이 돌아간다는 것을 유추하게 되었다.
