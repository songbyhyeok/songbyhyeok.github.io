# 소개
이 책은 2015년도에 발행한 책이다. 벌써 10년이나 지난 책이다 보니 IT 기술이 얼마나 빠르게 발전했는지 알 수 있다. 책의 주요 내용은 웹 통신에 필요한 기초적인 용어와 통신할 때 쓰이는 HTTP와 HTTPS 프로토콜의 내용 그리고 인증과 보안에 대한 기술적 용어에 대해서 다루고 있다.  

## 구매한 이유
내가 이 책을 구매한 이유는 웹을 처음 입문했을 때 HTTP가 생소했기 때문이다. 그리고 몇 번 읽고... 몇 년간 방치하게 되었다.  

## 스터디를 개설한 이유
죄책감이었을까? 사놓고 읽지 않았지만, 필요한 지식임은 틀림없었으니까! 꼭 완독을 해야겠단 결심이 어디서 솟아 나왔는지 모르겠다. 하지만, 혼자서 읽다간 지쳐 쓰러질 것만 같았다. 그래서 오래된 책이니 스터디를 개설해서 강제성을 부여해야겠다고 다짐했다.  

총 4명이서 정해진 시간에 같이 읽고 토론과 발표를 했더니 지루하진 않았던 것 같았다. 그리고 다른 사람들이 내가 학습하는 방식보다 더 효율적으로 학습하는 것을 보고 느끼며, 흡수해야겠다는 생각도 들었다.  

## 책을 마치며
삽화도 들어가 있고, HTTP 통신 개념에 대해 설명이 들어가 있어서 입문자용으로 추천할 만한 책은 맞다.  

그러나, 번역본의 한계일까? 뭉뚝하게 끊어지는 느낌을 잊을 수가 없다. 그리고 낡고 더 이상 쓰이지 않는 지식들을 학습하면서 굳이 이걸 알아야 할까? 라는
나쁜 생각도 많이 했던 것 같다.  

어찌 됐던 난 목표했던 완독을 했다.
