# 개요


# 구조체
C언어에는 클래스가 없고 대신에 구조체란 것을 제공하는데, 서로 다른 자료형을 갖는 하나의 집합 타입을 말한다. 사용자가 원하는대로 임의 자료형들을 넣어 타입을 만들 수 있기 때문에 사용자 정의 자료형이라고 한다.

## 정의 및 선언
```
struct 구조체이름 {
    멤버변수1의타입 멤버변수1의이름;
    멤버변수2의타입 멤버변수2의이름;
    ...
};

struct 구조체명 구조체변수명;

// 정의 및 변수 동시 선언
struct 구조체이름 {
    멤버변수1의타입 멤버변수1의이름;
    멤버변수2의타입 멤버변수2의이름;
    ...
} 구조체변수이름;
```

## typedef 키워드
이미 존재하는 타입에 새로운 이름을 붙일 때 사용, 구조체 선언 시 struct 키워드를 일일이 명시하지 않아도 됨으로써, 생산성을 높여줌
```
typedef struct 구조체이름 구조체의새로운이름;

typedef struct (구조체이름) {
    멤버변수1의타입 멤버변수1의이름;
    멤버변수2의타입 멤버변수2의이름;
    ...
} 구조체의새로운이름;
```

## 구조체 멤버 접근
```
구조체변수이름.멤버변수이름
```

구조체 멤버로 접근 시 멤버 연산자(.)를 사용

## 구조체 변수의 초기화
```
// 멤버 연산자(.)와 중괄호({})를 사용한 방법
구조체변수이름 = {.멤버변수1이름 = 초깃값, .멤버변수2이름 = 초깃값, ...};

// 배열 방식의 초기화 방법
구조체변수이름 = {멤버변수1의초깃값, 멤버변수2의초깃값, ...};
```

연산자 방식의 초기화는 원하는 멤버 변수만을 초기화할 수 이점이 있어, 배열 방식처럼 순차적으로 초기화하는 방식과 비교해서 좋을 수 있다. 다만, 멤버 변수가 정의된 순서와 초기화하는 순서는 아무런 상관이 없으며, 초기화하지 않은 멤버 변수는 0으로 초기화가 진행된다.

## 구조체 패딩
### 패딩?
구조체나 클래스를 구성하는 과정에서 메모리 정렬로 인한 **메모리에 저장된 데이터 크기 사이에 공백이 발생**하는 현상을 말한다. 이는, C언어의 구조체에서만 국한된 것이 아닌, 모든 언어에서 발생되는 범주적 개념이니 반드시 이해하는 것이 좋다.  

구조체는 멤버 변수, 함수를 지정 시 위에서 아래로 타입 크기가 큰 것부터 선언을 하는 것을 지향해야 한다. 해당 공간에 선언된 가장 큰 타입부터 메모리가 형성이 되며, '**내림차순**'으로 정렬되지 않는 타입들의 공간들은 '**패딩**'에 의하여, 메모리 사이를 큰 타입 크기에 맞게 알아서 채워주기 때문이다.

## 실험
패딩 현상을 포착하기 위해 실험을 진행한다.
위의 double은 8byte며 그다음 float 4byte, int 4byte다. 
처음에 8byte인 double이 채워지고 그 다음 float는 4byte기 때문에 그 다음 공간을 int가 채워주게 된다.
만약 float가 4byte 크기가 아닌 5byte였다면 메모리 패딩이 일어나서 float 혼자서 8byte를 차지하게 되고
그 다음 새로운 8byte에 int가 혼자서 차지하게 될 것이다.

(Float가 5칸을 차지함으로써 Int가 다음 8byte를 새로 생성된 공간으로 넘어갔다.)

# 비트필드
주기억장치의 기억공간을 byte단위가 아니라 bit 단위로 구성하여 메모리를 아낄 수 있는 키워드다.
구조체와 형식은 같으나 내부 필드 값을 다르게 지정해 주어야 한다.
Flag의 기억 메모리 공간은 총 4byte로 구성이 된다. 왜냐하면 a, b, c 가 잡아먹는 총 크기는 32bit로 4byte이기 때문이다.

만약 저기에 추가적인 비트 공간이 하나라도 더 있다면 Flag는 8byte 공간으로 늘어나게 될 것이다.
위 공간은 6byte 크기를 가지게 된다. a는 16비트로 하나의 short 공간을 차지한다, b와 c는 합해서 short 공간 하나
마지막으로 d는 4bit로 패딩으로 나머지 12비트가 채워진 총 6byte 공간을 차지하게 된다.
비트 필드 사용 시 주의사항으로는 unsigned를 사용하고 포인터, 배열은 사용이 안되며
실수형을 사용할 수가 없다는 것이다.

​# 공용체 Union
동일 기억장소에 여러 유형의 자료를 저장하여 상황에 필요 타입으로 변환하여 처리하는 유동적, 메모리를 효율적으로 사용하는 키워드다.
다른 공용체와 다르게 필드 값 중 가장 큰 메모리로 기억 공간을 할당하고 공용으로 사용한다.

```
union MyUnion {
    double d;
    floag f;
    int i;
    char c;
}
```

위와 같은 형식으로 사용이 된다.
```
MyUnion mu;
mu.d = 8.8;
mu.c = 'a';
```

라고 가정을 한다면 처음에 d가 가장 큰 값이니 8byte 공간을 잡고 그 다음 8.8이란 데이터를 저장한다.
그 다음 c가 'a'라는 데이터 1byte를 사용하면 8.8이 지워지고 'a' 데이터가 저장이 된다.
