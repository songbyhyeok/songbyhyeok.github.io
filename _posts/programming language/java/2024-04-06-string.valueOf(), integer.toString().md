# Integer.toString()과 String.valueOf()의 차이점
두 메서드는 파라미터 값 타입이 원시나 박싱에 따라 차이가 발생한다.  
작동 방식에 있어, Integer.toString()이고, String.valueOf()은 Integer.toString()을 포함한다. 원시값이나 Wrapper값 어느 것이 들어와도 두 메소드는 값을 잘 변환시켜 준다. 그러나 null인 경우 valueOf()는 null을 똑같이 반환하지만, toString()은 NullPointerException을 반환하게 된다. 그 이유는 toString이 원시값 타입만 받고 있기 때문이다.  

**valueOf()는 Wrapper 값을 처리할 수 있는 이유**  
valueOf()는 파라미터 타입이 Object가 들어올 경우 내부 설계가 오버라이딩이 되어 있어, 다르게 동작하게 되어 다른 메소드가 작동하게 되는 구조로 되어있기 때문이다.  

# 정리
두 메소드는 정수를 문자열로 반환하는 역할을 하지만 Wrapper 타입의 값이 null일 경우 toString()은 예외처리를 발생한다.
