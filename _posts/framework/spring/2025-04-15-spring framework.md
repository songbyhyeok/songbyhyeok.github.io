# 스프링이란?
스프링은 Java 기반의 애플리케이션 개발 목적으로 사용되는 오픈 소스 프레임워크를 말한다.  

### 스프링 프레임워크? 그리고 사용하게된 이유
프레임워크는 특정 목적을 달성하기 위해 기본 구조와 틀을 제공하는 재사용 가능한 코드 집합을 말하는데, 그러니까 한마디로 애플리케이션 개발을 용이하게 해준다.  

그런데, 왜 스프링 프레임워크는 없어서는 안되게 되었을까?  
* 초기 자바 엔터프라이즈 개발 환경은 J2EE 기반이었고, 대표적으로 EJB(Enterprise JavaBeans)를 중심으로 돌아갔기 때문
* EJB는 복잡한 구조, 단위 테스트 어려움, 무거운 성능, 높은 결합도, 설정 지옥 등 여러 가지 문제점들이 많았다.  

-> 위와 같은 문제점들을 개선하고자 나온 것이 바로 Spring Framework이다. 스프링은 2004년 첫 등장 이후, 이로부터 10년 후에 스프링 부트가 등장하게 된다.  

## 스프링 특징
### POJO(Plain Old Java Object)
스프링은 POJO 프로그래밍을 지향한다. 여기서 POJO란 순수 Java만을 통해서 생성한 객체를 의미하는데, 외부의 라이브러리, 모듈을 가져와서 혼합하지 않은 순수한 Java만을 사용하여 만든 객체를 의미한다.  

그렇다면 왜 스프링은 지향하는 것일까? 그 이유는 라이브러리로 사용된 기술이 더 이상 사용되지 않을 경우 유연하게 변화와 확장에 대처할 수 없기 때문이다.

### 의존성 주입 DI(Dependency Injection)  
의존성 주입은 객체가 직접 필요한 의존 객체를 생성하지 않고, 외부에서 주입받는 방식이다.  

기존에는 new를 통해 개발자가 직접 생성했다면, DI는 new를 더 이상 사용하지 않고 외부에서 그 의존 객체를 대신 주입하는 방식이다. 이로써 객체 간 결합도를 낮추고, 유연하게 구성할 수 있으며, 테스트를 쉽게할 수 있다.  

### 제어 역전 IoC(Inversion of Control)
전통적 프로그래밍에서 외부 라이브러리 코드를 개발자를 통해서 호출했다면, 제어 역전은 이와 반대로 스프링이 필요에 따라 외부 라이브러리 코드를 호출하는 개념을 말한다. 즉, 스프링이 외부 객체를 생성하여 의존 관계를 맺어주는 것을 IoC라고 한다.  

### 빈 생명 주기 관리
스프링 프레임워크는 Bean이라는 이름으로 Java 객체 혹은 컴포넌트의 생명주기를 직접 관리한다.  

### 관점 지향 프로그래밍 AOP(Aspect Oriented Programming)
핵심 로직과는 별개인 공통 관심사(로그, 보안, 트랜잭션 같은 공통 코드)를 애플리케이션 전반에 걸쳐 비즈니스 로직으로부터 분리해서 필요할 때마다 끼어 넣는 방식을 말한다.

## 스프링부트 그리고 차이
스프링부트는 스프링 첫 출시로부터 10년 후에 등장하게 된다. 스프링부트는 SpringFramework의 복잡한 설정 과정을 간소화하고 빠르게 개발할 수 있도록 처리해 주는 프레임워크를 말한다.  

스프링부트를 사용하면 다음과 같은 이점이 있다.  
* **자동 설정(Auto Configuration)**  
  * 기존 스프링 초기에 사용될 시간을 줄일 수 있다.  
* **내장 서버 지원(Embedded Server)**  
  * 기존엔 별도로 외장 웹 서버 및 War 파일로 빌드해야 했지만, 스프링부트는 자체 내장 웹서버를 내장하고 있어서 빠르고 간편하게 테스트, 배포할 수 있다.
* **스타터 의존성(Starter Dependencies)**  
  * Spring Boot는 특정 기능에 필요한 라이브러리를 묶어 제공하는 스타터 의존성을 제공한다.
    * ex: Spring MVC를 사용할 경우 spring-boot-starter-web 의존성을 추가하면 필요한 라이브러리들이자동으로 포함된다.
* **간편한 실행**  
  * 독립적으로 실행 가능한 Jar 파일로 프로젝트를 빌드할 수 있어, 가상환경이나 컨테이너에 빠르게 배포할 수 있다.
* **프로덕션 준비 기능(Production Ready Features)**  
  * Spring Boot는 애플리케이션 모니터링, 상태 점검, 메트릭 수집 등을위한 Actuator를 제공한다. 이를 통해 운영 환경에서도 애플리케이션을 효율적으로 관리할 수 있다.

## Spring WebFlux
Spring WebFlux는 Spring Web MVC에서는 지원하지 않는 비동기(Non-blocking)와 리액티브 프로그래밍(Reactive Programming)을 지원하기 위해 만들어진 스프링의 웹 프레임워크이다.
