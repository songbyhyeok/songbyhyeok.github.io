# 문제
[https://leetcode.com/problems/longest-palindromic-substring/description/](https://leetcode.com/problems/longest-palindromic-substring/description/)  
  
**(확장 방식의 투포인터 알고리즘)**  
두 칸 투포인터와 세 칸 투포인터만 사용하여, 양측 문자가 팰린드롬이면 확장하여 가장 긴 팰린드롬 찾는 알고리즘  
<br>

# 풀이  
## 왜 두 칸, 세 칸 포인터만 사용했을까?
팰린드롬은 양 끝 문자가 같고, 뒤집어도 같아야 하는 조건이 들어간다.  
만약 네 칸 포인터나 오 칸 포인터를 사용한 "abca", "abcaa"가 있다면 어.차.피 팰린드롬이 아니기 때문에 의미가 없다, 하지만 "aabc" 나 "abac" 는 팰린드롬 조건에 부합하기 때문에 두 개 혹 세 개 포인터를 사용하게 된다.  
이를 확장 사고 관점에서 보면 "abba"나 "cabac" 는 양 지점이 확장되어도 팰린드롬의 형태를 유지하기 때문에 효율적인 프로세스 처리가 가능하다.

## left와 maxLen 두 변수 값의 뜻과 용도
결론적으로 left는 현재 지점을 나타내고 maxLen은 팰린드롬의 길이를 나타내면서도 현재 지점에서 어디까지 나타낼 것인지 알려주는 용도이기도 하다.  
예를 들어 substring(left = 1, left = 1 + maxLen = 6)의 팰린드롬을 꺼낸다면 abcocba"와 같을 것이다.  
<br>

# 알고리즘 특징
* 두 칸 아니면 세 칸 투 포인터 확장 방식의 투포인터 알고리즘  
* 현재 가리킨 지점의 길이와 위치를 알 수 있다.  
<br>

# 시간복잡도
o(2n) + o(log n)  
-> 확장팰린드롬 메소드 각 o(n) + o(log n)  
<br>

# 코드  
```
// 출처: https://github.com/onlybooks/java-algorithm-interview
package ch06;

public class P6_1 {
    int left, maxLen;

    private void extendPalindrome(String s, int j, int k) {
        // 투 포인터가 유효한 범위 내에 있고 양쪽 끝 문자가 일치하는 팰린드롬인 경우 범위 확장
        while (j >= 0 && k < s.length() && s.charAt(j) == s.charAt(k)) {
            j--;
            k++;
        }

        // 기존 최대 길이보다 큰 경우 값 교체
        if (maxLen < k - j - 1) {
            left = j + 1;
            maxLen = k - j - 1;
        }
    }

    public String longestPalindrome(String s) {
        // 문자 길이 저장
        int len = s.length();

        // 길이가 1인 경우 예외 처리
        if (len < 2) return s;

        // 우측으로 한 칸씩 이동하며 투 포인터 조사
        for (int i = 0; i < len - 1; i++) {
            extendPalindrome(s, i, i + 1); // 2칸짜리 투 포인터
            extendPalindrome(s, i, i + 2); // 3칸짜리 투 포인터
        }
        // 왼쪽과 최대 길이만큼을 더한 오른쪽 만큼의 문자를 정답으로 리턴
        return s.substring(left, left + maxLen);
    }

    public static void main(String[] args) {
        String answer = new P6_1().longestPalindrome("dcbabcdd");
        System.out.println(answer);
    }
}
```
