# 문제
## [1 Two Sum Java](https://leetcode.com/problems/two-sum/description/)
level easy, lang java  

1. **BruteForce**  
   -> 2중 for문  
2. **Hash**  
    ->  C - B = A OR C - A = B  
3. **TwoPointer**  
    -> 시작점과 끝점을 사용하기  

<br>

# 풀이  
배열 요소의 두 개 값을 더했을 때 target이라면 두 요소 idx를 반환하는 문제다.  
해당 문제는 target 값을 반드시 구할 수 있는 전제가 들어가 있다.  
## BruteForce
2중 for문 i, j를 통해 두 값을 더해 target을 구할 수 있는 알고리즘 방식이다.  
예를 들어 int[] = {2, 6, 5, 7} 이고 target이 11이라면 i가 1이고 j가 2일 때 target 을 구할 수 있다.  
## Hash  
Hash Container에 배열 모든 요소의 값을 key, value를 idx로 구성하여 hash[target - 요소 값] 참조하여 구하는 방법이다.  
해당 방법은 target = a + b 일 때 역인 a = target - b 혹은 b = target - a 역 발상을 통해 피 연산자를 구하는 방법이다.  
## TwoPointer
시작과 끝에 가리키는 포인터를 두어 범위를 좁혀가며 target 값을 빠르게 찾는 방법이다.  
해당 알고리즘을 사용하기 위해선 array sort가 반드시 들어가야 한다. 하지만 두 idx를 구하는 문제이기 때문에 해당 알고리즘을 통해 풀 수가 없다.  
<br>

# 알고리즘 특징
1. BruteForce 방식은 직관적으로 모든 경우의 수를 빠르게 도출할 수 있다.  
2. Hash 방식은 a + b = target의 역인 a = target - b or b = target - a 의 idx를 참조하여 풀이 가능  
3. TwoPointer 방식은 양 포인터를 움직여 빠르게 target을 구할 수 있다.  
<br>

# 시간복잡도
* BruteForce = O(N^2)  
* Hash = O(1) or O(N)  
* TwoPointer = O(N)  
<br>

# 코드  
```
// BruteForce
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // brute force
        for(int i = 0; i < nums.length; i++) {
            for(int j = i + 1; j < nums.length; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[]{i, j};
                }
            }
        }

        return null;
    }
}
```
```
// Hash
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // hash map
        Map<Integer, Integer> map = new HashMap<>();
        for(int i = 0; i < nums.length; i++) {
            map.put(nums[i], i);
        }

        for(int i = 0; i < nums.length; i++) {
            if (map.containsKey(target - nums[i]) && i != map.get(target - nums[i])) {
                return new int[]{i, map.get(target - nums[i])};
            }
        }

        return null;
    }
}
```

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // two pointer
        int left = 0;
        int right = nums.length - 1;

        while(left < right) {
            if (nums[left] + nums[right] > target) {
                --right;
            } else if (nums[left] + nums[right] < target) {
                ++left;
            } else {
                return new int[]{left, right};
            }
        }

        // 항상 정답이 존재하므로 널이 리턴되는 경우는 없음
        return null;
    }
}
```
