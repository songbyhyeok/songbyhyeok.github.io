# 수치형 자료 그래프
사분위수(quartile)의 1에서 3까지의 범위의 네모 형태로 표현된 하나의 산포도 종류의 그래프 지표  
데이터의 최소값, 최댓값, 중앙값, 사분위수를 시각적으로 나타내는 그래프  
데이터의 분포와 중심 경향을 파악
## 구성  
### 사분위수
데이터를 4등분(25%)해서 표현한 것  
각사분위수마다 중앙값을 설정하여 데이터 분포를 측정할 수 있다.  
### 중앙값
두 값 사이의 밀도된 중간값  
* 홀수 = n + 1 / 2  
* 짝수 = [(n / 2)] + [(n / 2) + 1] / 2  

### IQR(InterQuartile Range)  
Q1과 Q3 사이의 길이  
### 이상치값 
일반적인 데이터 분포를 따르지 않는 값  
경계 범위 이상을 벗어난 값  
* **이상치 값 걸러내기**  
Q1이나 Q3 + 걸러낼 범위 경계 비율 1.5 * IQR
