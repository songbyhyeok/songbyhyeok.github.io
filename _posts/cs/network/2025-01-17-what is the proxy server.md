# Intro

# ProxyServer란?
클라이언트와 서버 중간에서 매개체 역할을 하는 하나의 프로그램이다. 

## 동작 원리
클라이언트 요청을 제공업체 ISP를 통해 프록시는, 이를 가로채서 사용자 IP를 자신의 IP로 둔갑시킨 후에 목적지 서버에 데이터를 보낸다.
이후, 처리된 응답 데이터를 다시 프록시에 들어오게 되면 프록시는 보안상 문제가 없는지 네트워크 보안 검사를 진행하고, 
이상이 없을 경우에 클라이언트에게 응답 값을 전달하게 된다. 프록시는 자주 요청되는 페이지를 캐시에 저장하여 데이터 전송 속도를 높인다.
다만, 프록시 자신의 IP를 악의적 목적을 가지고 역으로 사용자 정보나 요청.응답 간 데이터를 가로채기도 하는 문제점도 있다.  

프록시의 특징을 정리하면 다음과 같다. 네트워크 보안, 사용자 보호, 성능 향상(캐시 지원), 트래피 관리 제어  

프록시 동작 방식은 프록시 유형과 프로토콜 유형에 따라 달라질 수 있다.

## 장점
성 -> 사용자가 자주 방문하는 페이지를 캐시에 저장하여, 접근과 검색 속도 향상 그리고 대역폭 감소 성능 최적화
보 -> ip 은닉 및 방화벽
지 -> 접근이 힘든 지역적.국가적 사이트에 접속 가능, 사용자: 특정 지역.국가에서 제공하는 콘텐츠 소비 가능, 유연성 제공
제공자: 차단된 지역.국가에 접근 허용 사업을 통한 수입
콘 -> 프록시 관리자가 사용자 기록, 정보 기반으로 유해성 사이트 원천 차단 or 기업에서 직원들이 주의 분산, 부적절 콘텐츠 차단을 통해 자원 낭비 최소화와 생산성 증가
익 -> 중간에서 사용자 ip를 은닉하기 때문에 외부 사용자 데이터 수집과 광고를 원천 차단 가능.
