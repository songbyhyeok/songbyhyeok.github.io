**연결리스트 역순으로 구조 변경**  

# 풀이
![다운로드 (29)](https://github.com/user-attachments/assets/d6ed200e-5813-4816-bd9d-f1a46f02c193)  
연결리스트 구조를 뒤집는 방법에 있어 반복문과 재귀 두 가지 방법이 있다.  

## 반복문
위 그림의 1, 2, 3 과정을 현재 노드가 null일 경우인 4번 구조로 바뀔 때 까지 반복하면 된다.  
## 재귀
![다운로드 (30)](https://github.com/user-attachments/assets/dedfb325-f1e1-434e-a54e-f474ca195292)  
3번 과정의 그림처럼 현재 노드가 이전 노드를 가리키고 tail이 현재 노드에 현재 노드가 다음 노드의 주소로 이동 상태에서 재귀를 현재 node가 null일 때 까지 반복하고 tail을 반환하면 된다.  

# 코드  
```
// 반복문을 통한 구조 변경
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode node = head;
        ListNode tail = null;

        while(node != null) {
            final ListNode nextNode = node.next;
            node.next = tail;
            tail = node;
            node = nextNode;
        }

        return tail;
    }
}
```
```
// 재귀 접근
class Solution {
    private ListNode reverse(ListNode node, ListNode tail) {
        if (node == null) {
            return tail;
        }

        final ListNode nextNode = node.next;
        node.next = tail;

        return reverse(nextNode, node);
    }

    public ListNode reverseList(ListNode head) {
        return reverse(head, null);
    }
}
```
