# 문제
[https://leetcode.com/problems/palindrome-linked-list/](https://leetcode.com/problems/palindrome-linked-list/)  
  
**주어진 단일 연결리스트의 헤드를 사용하여 노드가 팰린드롬인지 여부를 반환하기.**  

# 풀이
## 1. Stack
스택 방법은 LIFO 특성에 따라 노드를 역순으로 비교할 수 있다.  
이를 위해 연결리스트를 순회하면서 각 노드의 값을 스택에 넣는다. 그리고 비교 과정 중 스택의 모든 요소를 비교할 필요는 없기 때문에 연결리스트의 크기를 알아내어, 크기의 절반만큼만 비교하도록 했다.  
## 2. Deque
덱 방법은 앞, 뒤로 노드를 꺼낼 수 있다. 따라서 하나의 자료구조를 통해 팰린드롬 여부를 도출할 수 있다.  
## 3. Runner(2개 포인트 동시 사용)
러너는 두 개의 노드 포인터를 사용하여 연결 리스트를 순회하는 기법이다.  
이를 통해 스택이나 덱보다 더 빠르게 팰린드롬 여부를 판단할 수 있다. 두 개의 포인터인 fast와 slow를 사용하여 slow가 절반 크기의 노드로 구성되도록 한다. slow 노드 형식은 다음과 같을 것이다.  
예를 들어, 1 -> 2 -> 3 -> 4의 경우 slow는 3 <- 4가 된다.  
slow는 절반 크기의 노드를 가지고 있으며, 이는 노드의 연결 구조를 역방향으로 나타내야 한다.  
마지막으로 head와 slow를 비교하며 팰린드롬 유/무를 확인하면 된다.  

# 코드  
```
// Stack 접근법
import java.util.Stack;

class Solution {
    public boolean isPalindrome(ListNode head) {
        Stack<Integer> stack = new Stack<>();
        ListNode newNode = head;

        while(newNode != null) {
            stack.push(newNode.val);
            newNode = newNode.next;
        }

        final int sLen = stack.size() / 2;
        for(int i = 0; i < sLen;  i++) {
            if (head.val != stack.pop()) {
                return false;
            }

            head = head.next;
        }

        return true;
    }
}
```

// Deque 접근법
class Solution {
    public boolean isPalindrome(ListNode head) {
        Deque<Integer> deque = new LinkedList<>();

        while(head != null) {
            deque.push(head.val);
            head = head.next;
        }
        
        while(!deque.isEmpty() && deque.size() > 1) {
            if (deque.pollFirst() != deque.pollLast()) {
                return false;
            }
        }

        return true;
    }
}

// Runner 기법
class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode fastNode = head, slowNode = head;
        
        while(fastNode != null) {
            fastNode = fastNode.next != null ? fastNode.next.next : fastNode.next;
            slowNode = slowNode.next;
        }

        ListNode revNode = null;
        while(slowNode != null) {
            ListNode nextNode = slowNode.next;
            slowNode.next = revNode;
            revNode = slowNode;
            slowNode = nextNode;
        }

        while(revNode != null) {
            if (head.val != revNode.val) {
                return false;
            }

            head = head.next;
            revNode = revNode.next;
        }

        return true;
    }
}
