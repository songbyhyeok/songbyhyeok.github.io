# 문제
[https://leetcode.com/problems/add-two-numbers/description/](https://leetcode.com/problems/add-two-numbers/description/)

**두 뒤집힌 연결리스트를 더해 새로운 연결리스트를 만드는 문제**  
주어진 두 연결리스트의 각 노드는 양수의 단일값을 구성하고 있으며, 각 연결리스트를 뒤집고나서 이 두 리스트를 더하고 다시 뒤집어 새로운 연결리스트를 반환하면 된다.  

# 풀이
문제를 풀기 앞서, 하나의 리스트의 범위는 1 ~ 100개까지 구성되어 있기 때문에 8byte의 범위를 벗어나게 된다.  
따라서 BigInteger 객체를 사용해야 한다.  
## 1. 각 리스트를 뒤집기  
## 2. 두 리스트의 합을 구하기  
값의 범위를 고려하여 각 리스트의 값을 BigInteger로 변환 후, 두 리스트의 합을 구한다.  
## 3. 산출된 값을 다시 뒤집기.  
산출된 값을 역순의 연결리스트로 만든다.  

# 코드  
```
// 반복문 접근 응용

import java.math.BigInteger;

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    private ListNode reverse(final ListNode head) {
        ListNode prev = null, node = head;
        while(node != null) {
            final ListNode next = node.next;
            node.next = prev;
            prev = node;
            node = next;
        }

        return prev;
    }

    private BigInteger toBigInteger(ListNode node) {
        String val = "";

        while(node != null) {
            val += node.val;
            node = node.next;
        }

        return new BigInteger(val);
    }

    private ListNode toReversedNode(BigInteger val) {
        ListNode prev = null;
        
        for(char c : String.valueOf(val).toCharArray()) {
            final ListNode node = new ListNode(Character.getNumericValue(c));
            node.next = prev;
            prev = node;
        }

        return prev;
    }

    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        final ListNode reversedL1 = reverse(l1);
        final ListNode reversedL2 = reverse(l2);
        final BigInteger total = toBigInteger(reversedL1).add(toBigInteger(reversedL2));
        return toReversedNode(total);
    }
}
```
