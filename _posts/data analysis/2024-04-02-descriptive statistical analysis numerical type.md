**최빈값**  
가장 자주 나오는 값   
**평균**  
범위의 중심값으로 대표하는 값을 말한다.
## 중앙값
**두 값 사이의 밀도된 중간값**  
홀수 = n + 1 / 2  
짝수 = [(n / 2)] + [(n / 2) + 1] / 2  
## 산포도
중심으로부터 흩어져 있는 정도
### 산포도 종류 
**범위**  
연속적인 값들의 개수  
R = max - min  
R은 max와 min에 영향만 받기 때문에 대푯값으로 사용 못함.  
**4분위**  
* 데이터 범위를 4등분 한 것  
-> 제1사분위수 25%  
-> 제2사분위수 50%  
-> 제3사분위수 75%  
-> 제4사분위수 100%  

상자도표 box plots 용도로 쓰임.  
이상치 outlier 값 제거 시 용이.  
대표 분포로 쓸 수 없다.  
각 사분위수에 대한 특징을 알 수 있다.  
**편차**  
중앙값 기준 떨어져 있는 각 데이터 거리  
**분산**  
편차의 합인 0을 만들지 않게 모든 합을 제곱하여 만든 식  
평균 중심으로 얼마나 광범위하게 분포하는지 나타내는 수  
데이터 측면에선 표본분산, 형태 측면에선 모분산이라고 표현  
표본분산에서 n - 1을 하는 이유는 대푯값이 고정되어 있기 때문(자유도)  
**표준편차**  
분석하는데 중요 지표로서, 제곱된 분산값을 원래 값 측정단위로 다시 전환한 값  
우리가 알고 싶어하는 모집단의 범위가 몇 퍼센트의 구간인지 알 수 있음.  
mad와 비교해서 루트 과정이 들어가 데이터 정확성이 떨어짐  
데이터측면 표본표준편차, 형태 측면 모표준편차   
## 표준화  
![다운로드 (1)](https://github.com/user-attachments/assets/2534e079-f2b9-4423-a3b8-1ef6132f6623)  
비교할 여러 대상들의 측정단위나 값 자체 등 관계없이 단순 숫자인 z값으로 변환시켜 비교하기 쉽게 만든 값  
* **[가정] 평균 20도, 표준편차 3**  
**case 1. 14도**  
-> z = 14 - 20 / 3 = -2  
**case 2. 23도**  
-> z = 23 - 20 / 3 = 1  

## 변동계수 
변동폭인 표준편차 대비 증가 비율을 알 수 있음.  
측정 단위가 다르거나 자료값 차이를 알고 싶을 때 사용.  
* **[가정]**  
**ex 어린이와 50대주부의 몸무게 분포 비교**  
-> 어린이 x바 20, s = 8, cv 0.40  
-> 50대주부 x바 55, s= 13 cv 0.23  
-> 어린이가 20kg에서 8kg 변한 게 비교해서 훨씬 더 많이 변했다고 해석  
**ex 키와 몸무게 비교**  
-> 키 x바 175 s 15 cv 0.09    
-> 키 x바 73 s 9 cv 0.12  
-> 73kg에서 9kg 증가한 게 훨씬 더 많이 변했다.
