# 문제
[https://leetcode.com/problems/reorder-data-in-log-files/](https://leetcode.com/problems/reorder-data-in-log-files/)   
  
**로그 파일을 요구조건에 맞게 처리해서 재배치하는 문제**   

```
Input: logs = ["dig1 8 1 5 1","let1 art can","dig2 3 6","let2 own kit dig","let3 art zero"]
Output: ["let1 art can","let3 art zero","let2 own kit dig","dig1 8 1 5 1","dig2 3 6"]
```

**조건**  
1. 로그의 가장 앞부분은 식별자로서, 순서에 영향을 끼치지 않는다.  
2. 문자로 구성된 로그가 숫자 로그보다 앞에 오며, 문자 로그는 사전순으로 한다.  
3. 문자가 동일한 경우에는 식별자 순으로 한다.  
4. 숫자 로그는 입력 순서대로 한다.  
<br>

# 풀이
## 1. 문자 로그와 숫자 로그 분리하기  

```
List<String> letterList = new ArrayList<>();
List<String> digitList = new ArrayList<>();

for(String log : logs) {
            if (Character.isDigit(log.split(" ")[1].charAt(0)))
                digitList.add(log);
            else 
                letterList.add(log);
}
```

**-> 두 자료구조 용도에 맞게 분리해서 담는다.**  
로그의 가장 앞 부분은 식별자이니 split 메서드를 사용해 두 번째 부분으로 문자인지 숫자인지 구별한다.  

## 2. 문자열 정렬 두 가지 방법  

```
Collections.sort(letterList, new Comparator<String>() {
            @Override
            public int compare(String s1, String s2) {
                String[] s1x = s1.split(" ", 2);
            String[] s2x = s2.split(" ", 2);

            final int compared = s1x[1].compareTo(s2x[1]);
            if (compared == 0)
                return s1x[0].compareTo(s2x[0]);

            return compared;
```

# 알고리즘 특징
문자열 처리와 정렬을 중심으로, 비교 기준과 데이터 구조 활용이 필요하며, 효율적인 시간복잡도와 문자열 다루기가 중요하다.

# 코드  
```
// Sort 1
class Solution {
    public String[] reorderLogFiles(String[] logs) {
        List<String> letterList = new ArrayList<>();
        List<String> digitList = new ArrayList<>();

        for(String log : logs) {
            if (Character.isDigit(log.split(" ")[1].charAt(0)))
                digitList.add(log);
            else 
                letterList.add(log);
        }

        Collections.sort(letterList, new Comparator<String>() {
            @Override
            public int compare(String s1, String s2) {
                String[] s1x = s1.split(" ", 2);
            String[] s2x = s2.split(" ", 2);

            final int compared = s1x[1].compareTo(s2x[1]);
            if (compared == 0)
                return s1x[0].compareTo(s2x[0]);

            return compared;
            }
        });

        letterList.addAll(digitList);
        return letterList.toArray(new String[]{});
    }
}
```
